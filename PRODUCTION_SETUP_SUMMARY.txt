4. BUILD & DEPLOYMENT COMMANDS
═════════════════════════════════════════════════════════════════════════════════

Development (Local):
  $ cd ecommerce
  $ npm install --legacy-peer-deps  (or yarn install)
  $ npm run dev                       (starts on port 3000)

Production Build:
  $ npm run build                    (compiles everything)
  $ npm run serve                    (runs production server)

Docker Compose (Includes MongoDB):
  $ docker-compose up -d             (starts both services)
  $ docker-compose down              (stops all services)
  $ docker-compose logs -f payload   (live logs)

Kubernetes / Cloud (Recommended):
  1. Build: docker build -t ecommerce:latest .
  2. Push: docker push your-registry/ecommerce:latest
  3. Configure: Update .env with production secrets
  4. Deploy: kubectl apply -f deployment.yaml (or Heroku, Vercel, Railway, etc.)
